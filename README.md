# Digital Steganography

A JavaFX-based desktop application that securely hides and extracts secret messages from images using steganography techniques.

## Features

* Hide secret messages inside images
* Extract hidden messages from encoded images
* AES encryption for enhanced security
* User-friendly JavaFX graphical interface
* Image processing and file handling

## Technologies Used

* Java
* JavaFX
* AES Encryption
* Object-Oriented Programming
* Image Processing

## Project Structure

src/
├── application/
└── steg/

## How to Run

1. Install Java 17 or above
2. Install JavaFX SDK
3. Clone the repository
4. Configure JavaFX libraries
5. Run Main.java
